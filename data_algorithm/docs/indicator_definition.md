# 국가·분야 협력기회 지표 정의서

기준 버전은 `v2.1-fixed-benchmarks`이며, 점수 계산은 LLM이 아닌 결정론적 Python 코드가 수행한다. LLM은 계산된 값과 연결된 공식 근거를 설명하는 역할만 맡는다.

## 1. 4대 점수

| 점수 | 구성요소 | 내부 비중 |
|---|---|---|
| 수요성 | 최근 5년 사업예산, 활성사업 수, 최근 착수 추세, 국가 내 분야 비중 | 35%, 25%, 20%, 20% |
| 정책 적합성 | 시간감쇠 적용 외교 신호, 참여기관 다양성, 최근 24개월 신호 수 | 50%, 30%, 20% |
| 실행 준비도 | 수행실적 사업 수, 수행기관 다양성, 최근 5년 연속성 | 40%, 30%, 30% |
| 한국 연계 기반 | 한국학 과정 깊이, 한류 동호회 수, 회원 수 | 55%, 20%, 25% |

## 2. 보조 지표

- 데이터 충족률은 분야 가중치에 따라 KOICA·KF·MOFA·LOD 원천의 존재 여부 40%, 최신성 30%, 출처 다양성 30%로 계산한다.
- 외교 신호에는 18개월 반감기의 지수 시간감쇠를 적용한다.
- 위험수준은 외교부 여행경보의 대상국 최대 단계를 별도 표시하며 기회점수에서 자동 차감하지 않는다. 사용자가 `max_risk` 필터로 제외할 수 있다.
- 결측치는 0과 구분해야 한다. 현재 점수는 원천 미수집으로 인한 0을 데이터 신뢰도와 제한사항으로 함께 표시한다.

## 3. 해석 제한

- KOICA 사업 원천이 없으면 수요성과 실행 준비도가 0에 가까워지므로 이 상태의 순위는 잠정 결과다.
- KF 한국학 통계는 공식 안내상 2016~2017 조사 기반이며 후속 갱신 시차가 있을 수 있다.
- 문서 수 자체는 점수로 직접 사용하지 않고, 중복 제거된 사업·기관·시간감쇠 신호를 사용한다.
