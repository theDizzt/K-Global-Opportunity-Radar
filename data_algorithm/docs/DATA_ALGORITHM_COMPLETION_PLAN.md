# 데이터·알고리즘 역할 완성 계획

## 1. 최종 목표

베트남·인도네시아·몽골의 외교·ODA·공공외교 데이터를 동일한 구조로 정리하고,
8개 분야에 대해 재현 가능한 세부지표와 종합점수를 계산한다. 모든 추천 결과는
기관명, 원문 URL, 자료 기준일, 계산에 사용된 지표까지 역추적할 수 있어야 한다.

### 최종 완료조건

- 3개국이 동일한 스키마와 동일한 수집 규칙으로 적재된다.
- 교육, 디지털, 보건, 농업, 기후·환경, 직업훈련, 한국어·한국학,
  문화·콘텐츠의 8개 공통 분야를 지원한다.
- 국가 종합점수와 국가×분야 점수를 모두 0~100 범위로 계산한다.
- 모든 점수 구성요소에 원천 레코드 또는 명시된 통계값이 연결된다.
- 모든 근거 레코드에 제공기관, 원문 URL, 수집일, 자료 기준일이 존재한다.
- 원본·정제·파생지표·점수 스냅샷이 서로 분리되어 보존된다.
- 동일 입력과 점수 버전으로 다시 실행하면 같은 결과가 나온다.
- 데이터량, 최신성, 특정 출처, 가중치에 대한 편향 검증 결과가 존재한다.
- 발표용 추천 결과 샘플과 데이터·산식 문서를 한 번에 재생성할 수 있다.

## 2. 현재 구현 상태

| 영역 | 상태 | 현재 결과 | 남은 핵심 작업 |
|---|---|---|---|
| KF 수집 | 부분 완료 | 사업·기관·실적 API 수집 및 원문 저장 | 한국학·한국어 기반 통계 자동수집/파일 적재 확정 |
| MOFA 공개 API | 부분 완료 | 관계·경제·여행경보 적재 | 기준일 추출 강화, 구조화 필드 확대 |
| 외교부 LOD | 부분 완료 | 보도자료·브리핑·발간물 SPARQL 수집 | 문서 유형·기관·이벤트 관계 추출 및 중복 검증 |
| KOICA | 코드 완료/실데이터 미완료 | 페이지네이션·상세조회·재시도 구현 | 3개국 전체 기간 실수집 성공 및 누락 점검 |
| MOFA 인사이트 | 조사 필요 | 자동수집 미구현 | 공개 범위·이용조건·대체 입력 방식 확정 |
| 국가 표준화 | 부분 완료 | VNM·IDN·MNG 및 기본 별칭 | 기관별 표기 사전, 미매핑 검출, 수정 이력 |

| 원본/정제 분리 | 부분 완료 | 원문 응답과 정규화 테이블 분리 | lineage ID, 정제 상태, 누락 사유, 오류 격리 |
| 지표·점수 | MVP 완료 | 4대 지표, 정규화, 시간감쇠, 신뢰도 | 지표 정의 확정, 3개국 정규화 편향 보정 |
| 추천 | MVP 완료 | 분야별 순위 및 설명 컨텍스트 | 사용자 조건, 가중치 변경, 상위 근거, 검토 후보 |
| 검증 | 부분 완료 | 단위·통합 테스트 9개 | 편향·민감도·수작업 대조·결측 시나리오 검증 |
| 문서/산출물 | 미완료 | 수집기 사용문서 일부 | 데이터 사전, 출처목록, 산식서, 검증보고서 |

## 3. 우선순위 원칙

- **P0 제출 필수:** 완료조건을 충족하지 못하면 추천 결과를 신뢰하기 어려운 작업
- **P1 완성도 강화:** 심사위원에게 근거성과 차별성을 보여주는 작업
- **P2 확장 기능:** 시간이 허용될 때 추가하는 기능
- 새로운 기능보다 데이터 계보, 재현성, 검증을 먼저 완성한다.
- LLM은 점수를 계산하지 않고 정해진 점수와 근거를 설명하는 역할만 맡긴다.

### Phase E. 분석용 데이터셋 생성 — P0, 1~1.5일

다음 7개 데이터셋 또는 DB 뷰를 고정한다.

| 데이터셋 | 핵심 내용 |
|---|---|
| `country_master` | 국가코드, 국가명, 권역, 기본 프로필 |
| `oda_project_fact` | KOICA 사업, 기간, 예산, 분야, 수행기관 |
| `diplomatic_activity_fact` | 외교활동, 협정, 회의, 보도, 기관 |
| `korea_base_fact` | 한국어·한국학·문화 기반 및 KF 기관 |
| `risk_fact` | 여행경보와 위험요인 |
| `cooperation_signal_yearly` | 국가×분야×연도별 사업·외교 신호 집계 |
| `evidence_document` | 추천 설명에 사용 가능한 원문 근거 |

완료 기준은 각 뷰에서 국가·분야·기준일·출처를 동일한 방식으로 조회할 수 있고,
건수 대조 쿼리가 존재하는 것이다.

### Phase F. 지표와 산식 확정 — P0, 2일

| 지표 | 권장 구성요소 | 핵심 통제 |
|---|---|---|
| 수요성 | 최근 ODA 예산, 신규사업 수, 성장추세, 분야비중 | 총사업량만으로 높아지지 않게 로그 변환·비중 병행 |
| 정책 적합성 | 협정, 고위급 교류, 공동사업, 공식 언급 | 이벤트 유형·출처 신뢰도·시간감쇠 적용 |
| 한국 연계 기반 | 한국학·한국어 과정, KF 기관, 문화 기반 | 단순 기관 수와 활동 깊이 분리 |
| 실행 준비도 | 완료·진행 사업, 수행기관 다양성, 연속성 | 오래된 완료사업의 영향 제한 |
| 데이터 충족률 | 필수 출처 확보율, 필드 완전성, 출처 다양성 | 점수 자체가 아니라 신뢰도와 함께 표시 |
| 데이터 최신성 | 출처별 최근 기준일과 갱신주기 | 반감기 또는 구간별 감쇠 적용 |

필수 산식 작업:

- 0~100 정규화 방식을 지표별로 명시한다.
- 3개국만으로 백분위 정규화하지 않고, 가능한 경우 전체 수원국·권역 모집단을 사용한다.
- 모집단 확보가 어렵다면 고정 기준점 또는 목표 범위를 사용한다.
- 이상치 완화를 위해 로그 변환과 상·하한 절단 규칙을 명시한다.
- 결측값은 0점과 구분하고 점수 신뢰도에서 차감한다.
- 분야별 기본 가중치와 그 근거를 문서화한다.
- `score_version`, `as_of_date`, 사용 데이터 버전을 함께 저장한다.

### Phase H. 알고리즘 검증 — P0, 2일

| 검증 | 방법 | 통과 기준 예시 |
|---|---|---|
| 단일 데이터 지배 | 구성요소 하나씩 제거하는 ablation | 한 요소 제거로 순위가 비정상적으로 전면 역전되지 않음 |
| 데이터량 편향 | 원문 수와 최종점수 상관 확인 | 단순 문서 건수가 점수의 사실상 대리변수가 아님 |
| 최신성 | 오래된 이벤트만 남긴 시나리오 | 최근 근거가 있는 국가보다 부당하게 높지 않음 |
| 가중치 민감도 | 각 가중치 ±20% 시나리오 | 순위 변동과 점수 범위를 보고서에 공개 |
| 결측 내성 | 출처 하나씩 제거 | 점수와 별도로 신뢰도가 하락하고 오류 없이 계산 |
| 수작업 대조 | 국가×분야 3~5건 직접 계산 | 프로그램 결과와 허용 오차 내 일치 |
| 재현성 | 동일 스냅샷 2회 실행 | 점수·순위·근거 ID 완전 일치 |
| 분류 정확도 | 라벨링 검수셋 평가 | 분야별 precision/recall과 오분류 목록 제공 |
| 극단값 | 대형 사업 1건 삽입 시뮬레이션 | 로그/상한 규칙이 과도한 지배를 억제 |

검증 결과는 성공 항목뿐 아니라 한계와 보완 예정 사항도 함께 기록한다.

## 5. 권장 일정

1인 데이터·알고리즘 담당 기준으로 필수 범위는 약 13~16인일이다.

| 구간 | 기간 | 목표 |
|---|---:|---|
| 1차 | D+1~D+2 | 출처 확정, 국가·분야 표준, 데이터 계약 |
| 2차 | D+3~D+5 | KOICA/KF/MOFA/LOD 3개국 전체 수집 |
| 3차 | D+6~D+7 | 정제·중복·lineage·분석 뷰 |
| 4차 | D+8~D+10 | 지표 산식과 8개 분야 점수 |
| 5차 | D+11~D+12 | 추천 필터·가중치·근거 추출 |
| 6차 | D+13~D+14 | 편향·민감도·수작업 검증 |
| 7차 | D+15~D+16 | 산출물 자동생성, 발표 샘플, 최종 QA |

일정이 부족하면 P1 기능을 줄이되, 출처·lineage·산식·검증은 줄이지 않는다.

## 6. 바로 착수할 순서

1. 8개 분야 코드와 포함/제외 기준을 확정한다.
2. 국가명 매핑표와 출처 카탈로그 스키마를 만든다.
3. KOICA 3개국 전체 실수집을 성공시키고 API 총건수와 대조한다.
4. KF 한국학·한국어 기반 데이터의 실제 제공 경로를 확정한다.
5. MOFA 인사이트 이용조건을 확인하고 수집 여부를 결정한다.
6. 공통 lineage·누락사유·날짜정밀도 필드를 DB에 추가한다.
7. 교육·디지털 두 분야를 먼저 정제하고 수동 검수한다.
8. 정규화 모집단과 고정 기준점을 확정한다.
9. 교육·디지털 점수를 수작업 계산과 대조한다.
10. 나머지 6개 분야 확장 후 검증·산출물 생성으로 마무리한다.
