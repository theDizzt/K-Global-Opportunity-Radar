# 자동 수집 권장 데이터

이 문서는 K-Global Opportunity Radar의 현재 산식과 데이터 계약을 기준으로 자동
수집할 자료의 우선순위와 권장 갱신 주기를 정리합니다.

## 1. 우선순위 A: 자동 수집 핵심 데이터

| 데이터 | 제공기관·수집 방식 | 활용 | 권장 주기 | 인증 |
|---|---|---|---|---|
| 외교일지·보도·간행물 | 외교부 LOD SPARQL | 외교 신호, 정책 근거, 근거 카드 | 매일 | 불필요 |
| 글로벌 e-스쿨 강좌 | KF 공개 표 | 한국어·한국학 기반, 인적교류 | 주 1회 | 불필요 |
| 국가 관계·경제·여행경보 | 외교부 공공데이터포털 API | 실행 준비도, 국가 프로필, 위험 분리 | 매일 또는 주 1회 | 필요 |
| KF 사업·참여기관·실적 | KF 공공데이터포털 API | 한국 연계기반, 수행기관 후보 | 주 1회 | 필요 |
| KOICA 사업 목록 | KOICA 사업정보조회 API | 협력 연속성, 수행 경험, 사업 근거 | 주 1회 | 필요 |

기본 자동 작업은 호출 부담이 낮은 `LOD`와 `KF 글로벌 e-스쿨`만 매일 수집합니다.
인증형 KF·MOFA는 `-IncludeAuthenticatedSources`, KOICA는 `-IncludeKoica`로
명시적으로 추가합니다.

KOICA 상세조회 API가 안정화되기 전에는 `--list-only`를 사용합니다. 자동 작업은
과도한 전체기간 재호출을 피하기 위해 기본적으로 최근 3개 연도만 수집합니다.

## 2. 우선순위 B: 저빈도 배치 데이터

| 데이터 | 활용 | 권장 주기 | 자동화 방식 |
|---|---|---|---|
| OECD CRS 전체 공여국 활동 | 공여국 포화도, 한국 점유율, 공급 모멘텀 | 신규 연도 공개 시 또는 분기별 | 대용량 파일 배치 적재 |
| World Bank 개발지표 | 교육·보건·디지털 미충족 수요 | 월 1회 | bulk ZIP 수집 |
| KF 해외대학 한국학 현황 | 한국학 과정과 연구 기반 | 공식 원본 갱신 시 | 검증된 파일 적재 |
| 해외안전여행 세부 안전정보 | 주의 요인과 실행 리스크 | 매일 또는 주 1회 | 공식 API·공식 파일 |

이 자료는 일별 변화가 적거나 파일이 크기 때문에 기본 일일 작업에 포함하지 않습니다.
OECD CRS와 World Bank 자료는 신규 다중 모델용 DB에 적재되며, 현재 화면의 기존
종합점수와는 분리해서 관리합니다.

## 3. 우선순위 C: 검토 후 반영할 데이터

| 데이터 | 이유 | 반영 조건 |
|---|---|---|
| 외교부 공식 정책문서의 사업 합의·착수 근거 | 정책 정합성의 강한 근거 | 서로 다른 2인의 검토 일치 |
| 현지 정부의 국가개발계획·분야 전략 | 실제 정책 수요 확인 | 공식 도메인·기준일·원문 보존 |
| 현지 파트너 기관·대학·기업 목록 | 실행 가능한 협력모델 구성 | 기관 식별자와 출처 검증 |
| 조달·예산·사업 공고 | 실제 진입 시점 판단 | 중복 제거와 마감일 검증 |

텍스트에서 자동 추론한 정책 근거는 바로 점수에 넣지 않습니다. 현재 파이프라인의
`review_required → 2인 검토 → 승인/거절` 절차를 거쳐야 합니다.

## 4. 자동 수집 운영 원칙

1. 원문과 가공 결과를 분리하고 원문 URL·수집 시각·요청 정보를 보존합니다.
2. ISO3 국가 코드와 8개 분야 코드를 정규화한 뒤 점수 계산에 사용합니다.
3. 같은 범위를 재실행해도 upsert와 안정 ID로 중복을 만들지 않습니다.
4. 한 출처가 실패해도 나머지 출처는 계속 수집하고 실행 보고서에 실패를 기록합니다.
5. 동시에 두 작업이 실행되지 않도록 파일 잠금을 사용합니다.
6. 수집이 성공한 경우에만 기존 점수를 다시 계산하고 FastAPI DB에 동기화합니다.
7. 신규 다중 모델은 검증 상태와 데이터 충족률을 유지하며 기존 종합점수와 섞지 않습니다.
